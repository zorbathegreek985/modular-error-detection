# R8 Deep Prior-Art Comparison

## Scope and access record

This comparison uses the project definitions in [formal_model.md](formal_model.md) and the actual R6 profile API in [detection_profile_engine.md](detection_profile_engine.md) and `python/modular_error_detection/profiles.py`. It refines, rather than replaces, the bounded conclusions in [the R7 matrix](prior_art_claim_matrix.md) and [R7 novelty boundary](novelty_boundary.md).

### Access status

- **Verhoeff (1969): full text inspected.** The CWI institutional repository provides a 135-page scan of *Error Detecting Decimal Codes*. Relevant portions inspected include §0.5 (error statistics), §2.3.3 (weighted modular decimal checks), the modulus-11 discussion, §3.2 (conditions), §§3.3–3.4 (rate-preserving transformations and search program), and the bibliography.
- **Schulz (2001): full text inspected.** The author's openly hosted 12-page chapter “Check Character Systems and Anti-symmetric Mappings” was read for the group model, detection conditions, weak/strong equivalence, and computed classes.
- **Gumm (1985): complete author-hosted PDF located, but not successfully inspected.** Gumm's university publications page links a four-page copy, `ANewClassOfCheckDigitMethods.pdf`. The PDF endpoint was accessible, but the reader returned no extracted text and its page-render attempts failed. The publisher full text was not accessible. The abstract and an author-hosted 1986 follow-up were available through indexed material. Thus this is **not a full-text review** of the 1985 article. The author-hosted copy appears intentionally public, but no license statement was visible; no third-party upload was used as a substitute.
- **Damm (2000): full article not inspected.** The Springer/DOI page did not expose the article text. An author-hosted Schulz chapter gives Damm's group-theoretic result and cites the relevant Damm work; this is secondary evidence, not a substitute for the 2000 article. The Marburg repository record for Damm's 2004 dissertation exists, but its PDF endpoint redirected to an access-denied page. The dissertation is a different work and is not conflated with the 2000 paper.
- **Other primary/official material:** Hamming's publisher record and a short open extract; ISO's official abstract/preview; the International ISBN Agency FAQ; Luhn's patent; and the Oxford publisher abstract for Abdel-Ghaffar were inspected. Those sources support only the claims and level of detail specified in the matrix below.

## What the sources establish mathematically

### The project is a weighted modular specialization

For \(S(x)=\sum_iw_ix_i\pmod m\), changing coordinate (i) from (a) to (b) changes the syndrome by

\[
\Delta=(b-a)w_i\pmod m.
\]

Swapping (a,b) in positions (i,j) changes it by

\[
\Delta=(b-a)(w_i-w_j)\pmod m,
\]

up to sign. These statements follow by subtraction. The project takes (w_k=10^k) and compares the original and altered residues. It uses no appended check digit. However, for each fixed residue (r), the set \(\{x:S(x)=r\}\) is a check-equation class, so the event-detection criterion is the same difference test used for a linear checksum code. The model distinction is about what the project reports and how strings are represented, not about a novel syndrome algebra.

Verhoeff §2.3.3 explicitly treats the weighted modular setting. At p. 55 in the monograph's page numbering, the mod-11 weighted discussion says nonzero weights are admissible for all single errors and analyzes transpositions through unequal weights. In the mod-10 examples earlier in the same subsection, a period-four geometric weighting produces a missing adjacent-swap case when digit differences satisfy the corresponding congruence. Those are concrete instances of the general weighted delta test. Verhoeff did not write the project's gcd-reduced expression in the inspected sections; that is a simple reformulation using Euclid's lemma.

### Exact interpretation of (W(h))

For any integer coefficient (q), the undetected ordered-pair count at a weighted position is

\[
U(m,q)=\#\{(a,b)\in\{0,\ldots,9\}^2:a\ne b,\ m\mid q(a-b)\}.
\]

Let (h=m/\gcd(m,q)). By gcd cancellation, this is exactly

\[
U(m,q)=\#\{(a,b):a\ne b,\ h\mid(a-b)\}=W(h).
\]

The last equality and the closed sum are direct derivations: for each positive difference (hj\le9), there are (10-hj) ordered pairs in one orientation and the same number in the reverse orientation. This establishes mathematical equivalence between (W(h)) and the general weighted-check miss count; it does not establish prior publication of the closed form as a general named formula.

Verhoeff's mod-10 weighted example provides an explicit instance. For (m=10,q=2), (h=5); (W(5)=2(10-5)=10) ordered missed pairs, or 5 unordered pairs. His text reports 8 of 9 transposition-difference classes detected, which is the same 40/45 unordered-pair rate because only digit difference 5 is missed. So the underlying count idea and special cases are not new; a general concise (W(h)) statement remains **not located** in the sources inspected.

### Stabilization and universal detection

The stable values

\[
h_s(m,k)=\frac{m}{\gcd(m,10^k)},\quad
h_t(m,k)=\frac{m}{\gcd(m,9\cdot10^k)}
\]

follow by prime valuations once powers of 2 and 5 in the positional coefficient have canceled. The residual factor 3 in (h_s), and residual (3^{\max(b-2,0)}) in (h_t), follows from the fixed coefficient 9 in the transposition delta. This is a short arithmetic derivation. Verhoeff discusses periodic powers modulo 10 and weighted sequence design, but no matching reduced-gcd stabilization result was found in the inspected text. No claim of novelty follows.

Similarly, the project criterion (h>9) is the finite digit-difference bound for decimal digits. Verhoeff already analyzes universal detection constraints for modular weights and mod 11, so the broad idea and guarantees are established. The project's exact factorized all-length test is a specialization; it has not been located verbatim.

## Gumm: exact relation and limits

Gumm's 1985 abstract describes a **single-check-digit** method for arbitrary number systems, using dihedral groups with suitable transformations in cases where the base is (2r) for odd (r), and states guarantees for all single-digit and adjacent-transposition errors. The available author's 1986 follow-up, “Encoding of Numbers to Detect Typing Errors,” likewise describes digits acted on by powers of a permutation and combined with a dihedral-group operation; it states that the resulting check digit detects all single-digit and adjacent-transposition errors. These are nonlinear/group-valued check-digit systems. “Arbitrary number systems” in the abstract refers to number bases under the article's construction, not arbitrary linear weight vectors or arbitrary moduli in \(\sum_iw_ix_i\pmod m\).

Because the original 1985 proof could not be extracted, this review cannot report its theorem numbering, exact check equation, detailed hypotheses, rate computations, or search. In particular it does **not** establish that Gumm states either scalar divisibility formula from the project. The R6 formulas are not implied merely by Gumm's universal-error guarantee. At most, the two bodies of work share the objective of detecting single errors and adjacent swaps using one check symbol/residue-like redundancy, under different algebraic models. The weight differences in the project do not become Gumm's group transformations simply by relabeling.

## Damm and Schulz: exact relation and limits

The 2000 Damm article's abstract characterizes existence of group check systems that detect all single errors and adjacent transpositions by anti-symmetric mappings. The inspected Schulz chapter gives the operational model: a group (G=(A,\cdot)), position permutations \(\delta_i\), and a check equation \(\delta_1(a_1)\cdots\delta_n(a_n)=e\) (Eq. (1), p. 137). Every single error is detected when the position maps are permutations; adjacent transpositions are detected exactly when the condition in Eq. (2) holds, and for \(\delta_i=T^i\) this is anti-symmetry \(xT(y)\ne yT(x)\) (Eq. (3)). These are group-operation conditions, not scalar modular/gcd conditions.

Schulz's §3 studies equivalence **between group permutations and their corresponding check-character systems**. Weak equivalence transforms a map using left/right translations and a group automorphism (Definition 3.1.1, p. 143); automorphism and strong equivalence are defined later (§3.2, p. 144). The chapter specifically warns that weakly equivalent schemes need not have identical rates for every error class; it states the rates/invariants it does prove. It then reports computational classes for anti-symmetric mappings over the dihedral group (D_5) (§3.2, pp. 144–145), citing Verhoeff and Damm among others.

The project relation compares **observable sequences of counts/rates indexed by position for two integer moduli**. It is not Schulz's transformation equivalence. It is analogous in purpose—group systems into classes according to preserved behavior—but has different objects and invariants. If the project includes (h) itself as a profile component at (k=0), then (h_s(m,0)=m), so profile equality forces (m_1=m_2). That definition cannot yield nontrivial classes. A nontrivial version must compare only observable outcomes/counts/rates and specify the position/length domain. Such a relation is easy to define; its value and prior-art distinction remain open.

## Findings for the R8 questions

### (W(h))

Conclusion: **E — the underlying count is used in prior weighted-check analyses and equivalent examples are explicit; the generic closed sum is not located in the reviewed text.** For a linear checksum, the expression \(\#\{(a,b):a\ne b, m\mid q(a-b)\}\) is exactly the set of undetected digit substitutions or swaps when (q) is the relevant weight or weight difference. Thus the count is already implicit in the general weighted error condition. Verhoeff's mod-10 (q=2) example supplies a concrete (W(5)) instance. The project's (W(h)) formula is an elementary closed form for this finite count; whether it appears in another source/notation remains unverified.

### Stabilization

Conclusion: **Not located in literature reviewed.** Verhoeff's discussion of periodic powers modulo 10 and weight sequences is related, but no exact (m/\gcd(m,10^k)) or (m/\gcd(m,9\cdot10^k)) prime-factor stabilization formula was found in the inspected text. These are short valuation calculations. This is not a novelty claim.

### Profiles

Conclusion: **The profile is an implementation/presentation of established position-dependent quantities.** Verhoeff calculates position-sensitive conditions, code rates, and transformations; Schulz compares behavior of group schemes. No exact bundle consisting of the project's (h,W(h)), pair counts, rates, and flags was located. That bundle is still only a representation until a theorem or use beyond convenience is shown.

### Equivalence

Conclusion: **There are clear prior analogues, but the objects differ.** Schulz defines structural equivalences of group permutations/check systems and investigates which detection properties/rates they preserve. Verhoeff studies rate-preserving transformations. The project's equality of output profiles is a behavioral quotient of integer moduli, not the same relation. If (h) is included at position zero, equality is trivial; only a rates/counts-only relation over a declared domain can produce distinct-modulus classes.
